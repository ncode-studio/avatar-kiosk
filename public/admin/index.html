Modalità AI

        

          

            
            
            
            
          

        

        


          
          

            
            
          


          
          

            
Headers 

            
            
Esempio con autenticazione:

              {"Authorization":"Bearer il-tuo-token", "X-Api-Key":"chiave"}
            

          


          
          

            
Body 

            
            

              Usa {{query}} come segnaposto per il messaggio dell'utente.

              Esempio n8n: {"message":"{{query}}", "sessionId":"abc123"}

              Esempio con contesto: {"input":"{{query}}", "language":"it"}
            

          


          
          

            
Response

            
            

              Campo JSON della risposta da mostrare. Usa il punto per annidare.

              Esempio: response → {"response":"Ciao!"}

              Esempio annidato: data.message → {"data":{"message":"Ciao!"}}
            

          


          
          

        


        


          

            
            
            
Endpoint HTTP del MCP server (Streamable HTTP transport). I tool disponibili vengono passati automaticamente al modello AI.

          


          

            
Headers 

            
            
Header di autenticazione per il MCP server.

              Esempio: {"Authorization":"Bearer il-tuo-token"}
            

          


          

            
Filtro tool

            
            

              Nomi dei tool da esporre al modello, separati da virgola. Lascia vuoto per esporre tutti i tool del MCP server.
            

          


          

            
            

              Se attivo, l'output del tool MCP viene inviato direttamente all'utente senza reinviarlo a Claude/OpenAI.
              Riduce latenza e costi, ma la risposta non verrà riformulata nello stile dell'avatar.
            

          


          
          

        


        


          

            
            
            
URL base del servizio. Il sistema cerca automaticamente uno spec OpenAPI/Swagger e ne ricava le API, che l'AI userà come strumenti.

          


          

            
            
            
Inviato come Authorization: Bearer <token> sia nella discovery che nelle chiamate.

          


          

            
URL spec (opzionale)

            
            
Solo se l'auto-detect non trova lo spec. Path provati automaticamente: /openapi.json, /swagger.json, /v3/api-docs, /api-docs…
